# FRD

## 문서 목적

이 문서는 제품 기능 요구사항과 화면 상태/조건을 정의한다.

## 기능 범위

- 인증 및 회원가입
- 홈 대시보드 및 상태 확인
- 차량 진단 진행 및 결과 조회
- 예약 생성 및 완료
- 정비/진단 이력 조회
- 내 정보 및 차량/연동 관리

## 기능 목록

### 1. 인증 및 계정 진입

- 설명:
  - 사용자는 로그인, 회원가입, 계정 찾기 기능을 통해 앱 사용 가능 상태가 되어야 한다.
- 진입 조건:
  - 앱 최초 실행
  - 인증 만료
  - 로그아웃 상태
- 출력 결과:
  - 인증 성공 시 `HOME_MAIN_S` 진입
  - 실패 시 에러 상태 안내

세부 요구사항:

- 로그인 방식 선택이 가능해야 한다.
- 이메일 로그인 입력과 오류 상태를 분리해서 보여줘야 한다.
- 회원가입은 약관 동의, 입력, 권한 동의, 완료 단계를 순차적으로 제공해야 한다.
- 아이디/비밀번호 찾기 화면에 접근 가능해야 한다.

### 2. 홈 대시보드

- 설명:
  - 사용자는 홈에서 현재 차량/정비 상태와 주요 서비스 진입점을 한 번에 확인해야 한다.
- 진입 조건:
  - 로그인 성공 후 기본 진입
  - 글로벌 내비게이션에서 홈 탭 선택
- 출력 결과:
  - 현재 상태 배너 표시
  - 서비스 메뉴/추천/알림 상세 진입

세부 요구사항:

- 홈 메인 화면은 상태 요약과 서비스 진입 허브 역할을 수행해야 한다.
- 경고/알림 상세와 정비 관련 상세 화면으로 이동 가능해야 한다.
- 데이터가 없거나 시스템 문제가 있으면 `HOME_EMPTY_S`, `HOME_ERROR_S`를 제공해야 한다.

### 3. 진단 기능

- 설명:
  - 사용자는 차량 진단을 시작하고, 진행 상태와 결과를 확인할 수 있어야 한다.
- 진입 조건:
  - 홈 또는 글로벌 탭에서 진단 영역 진입
- 출력 결과:
  - 진단 메인, 진행, 결과, 빈 결과, 시스템 상태 제공

세부 요구사항:

- 진단 시작 전 메인 진입 화면이 있어야 한다.
- 진행 중 화면은 현재 프로세스 상태를 명확히 보여줘야 한다.
- 결과 화면은 진단 요약과 후속 액션 가능성을 제공해야 한다.
- 결과 없음, 시스템 오류, 데이터 없음 상태를 분리해 표시해야 한다.

### 4. 예약 생성 기능

- 설명:
  - 사용자는 정비/소모품 항목 선택부터 정비소, 일정, 확인, 완료까지 예약 전 과정을 진행할 수 있어야 한다.
- 진입 조건:
  - 홈 또는 글로벌 탭에서 예약 진입
  - 진단 결과 이후 후속 예약 유도
- 출력 결과:
  - 예약 완료 또는 예외 상태 진입

세부 요구사항:

- 예약 유형 또는 대상 선택 화면이 필요하다.
- 추천 항목, 항목 리스트, 항목 상세를 제공해야 한다.
- 정비소는 리스트/지도/상세 형태로 탐색 가능해야 한다.
- 일정 선택 후 예약 확인과 완료 화면으로 이어져야 한다.
- 예약 불가/데이터 없음/시스템 오류 상태를 구분해야 한다.

### 5. 이력 조회 기능

- 설명:
  - 사용자는 과거 정비 이력과 진단 이력을 조회하고 상세를 확인할 수 있어야 한다.
- 진입 조건:
  - 글로벌 탭에서 이력 영역 진입
  - 홈 또는 진단/예약 이후 후속 진입
- 출력 결과:
  - 메인 이력 화면 및 상세 화면 제공

세부 요구사항:

- 메인 이력 화면은 서비스 이력과 진단 이력으로 진입 분기를 제공해야 한다.
- 상세 화면은 각각 독립 구조로 제공해야 한다.
- 데이터가 없거나 시스템 문제가 있으면 별도 상태 화면을 보여줘야 한다.

### 6. 내 정보 및 관리 기능

- 설명:
  - 사용자는 자신의 차량 정보, 자동 예약, 가이드, 연동 설정을 확인/관리할 수 있어야 한다.
- 진입 조건:
  - 글로벌 탭에서 내 정보 영역 진입
- 출력 결과:
  - 설정/관리 작업 완료 또는 세부 정보 확인

세부 요구사항:

- 차량 등록 화면이 있어야 한다.
- 자동 예약 관련 화면에 접근 가능해야 한다.
- 차량 가이드 상세와 연동 관련 화면이 제공되어야 한다.

## 상태 정의

### 기본 상태

- 각 도메인의 메인 화면
- 데이터가 정상적으로 존재하는 상세/리스트/진행 화면

### 로딩 상태

- 인증 처리 중
- 진단 진행 중
- 예약 가능 데이터 조회 중
- 이력 데이터 로딩 중

### 빈 상태

- `HOME_EMPTY_S`
- `DIAG_EMPTY_S`
- `DIAG_RESULT_EMPTY_S`
- `RSV_EMPTY_S`
- `RCD_EMPTY_S`

### 에러 상태

- `AUTH_LOGIN_ERROR_P`
- `HOME_ERROR_S`
- `DIAG_ERROR_S`
- `RSV_ERROR_S`
- `RCD_ERROR_S`

### 완료 상태

- `AUTH_SIGNUP_COMPLETE_S`
- `RSV_COMPLETE_S`

## 사용자 액션

### 인증 액션

- 액션: 로그인 시도
  - 트리거: 로그인 입력 완료 후 CTA 선택
  - 결과: 홈 진입 또는 로그인 에러 표시

- 액션: 회원가입 진행
  - 트리거: 회원가입 진입 후 단계별 입력/동의 완료
  - 결과: 가입 완료 화면 도달

### 홈 액션

- 액션: 알림/정비 상태 상세 확인
  - 트리거: 홈 카드 또는 배너 선택
  - 결과: 상세 화면 진입

- 액션: 주요 서비스로 이동
  - 트리거: 홈 서비스 진입 요소 선택
  - 결과: 진단/예약/이력/내 정보 영역 진입

### 진단 액션

- 액션: 진단 시작
  - 트리거: 진단 메인에서 시작 CTA 선택
  - 결과: 진행 화면 진입

- 액션: 진단 결과 확인
  - 트리거: 진행 완료 또는 결과 화면 진입
  - 결과: 요약 정보 및 후속 액션 확인

### 예약 액션

- 액션: 예약 대상 선택
  - 트리거: 추천/리스트/상세 화면에서 항목 선택
  - 결과: 정비소 선택 단계로 이동

- 액션: 정비소 및 일정 선택
  - 트리거: 리스트/지도/상세/일정 화면에서 선택 완료
  - 결과: 확인 화면 진입

- 액션: 예약 확정
  - 트리거: 확인 화면 CTA 선택
  - 결과: 완료 화면 진입

### 이력 액션

- 액션: 이력 상세 진입
  - 트리거: 이력 리스트 또는 탭 내 항목 선택
  - 결과: 서비스/진단 상세 화면 진입

### 내 정보 액션

- 액션: 차량 등록 또는 설정 진입
  - 트리거: 내 정보 메뉴 선택
  - 결과: 해당 관리 화면 진입

## 데이터 요구사항

### 공통 데이터

- 사용자 인증 상태
- 차량 기본 정보
- 글로벌 상태 정보

### 홈

- 차량 상태 요약
- 정비 진행 상태
- 알림/정비 상세 진입 정보
- 서비스 메뉴 데이터

### 진단

- 진단 가능 상태
- 현재 진행 단계
- 진단 결과 요약
- 진단 코드/세부 결과

### 예약

- 예약 대상 항목
- 추천 항목 데이터
- 정비소 리스트/지도 정보
- 예약 가능 일정
- 예약 확인 정보

### 이력

- 정비 이력 목록
- 진단 이력 목록
- 각 상세 데이터

### 내 정보

- 차량 등록 정보
- 자동 예약 설정 정보
- 가이드 콘텐츠
- 외부 연동 상태

### 외부 연동 여부

- 인증 방식에 따라 외부 로그인 연동 가능성 존재
- 지도 기반 정비소 탐색은 외부 지도 데이터 연동 가능성 존재
- 연동 화면은 외부 서비스 연결 상태를 반영해야 할 수 있음
