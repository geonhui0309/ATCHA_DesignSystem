## 화면 목적

- 예약이 정상 완료되었음을 확인시킨다.

## 주요 사용자 시나리오

- 사용자는 예약이 정상적으로 확정되었는지 즉시 확인한다.
- 사용자는 예약된 정비소명, 일시, 예약 항목을 다시 확인한다.
- 사용자는 닫기 또는 예약 상세 화면 진입 중 하나를 선택한다.

## 사용된 patterns

- 별도 pattern 없이 완료 확인 레이아웃 중심

## 사용된 components

- `NavigationBar`
- `Button`
- `ScreenContainer`
- `Stack`

## 상태 variation

- 완료 아이콘 강조
- 정비소명/예약 시간/예약 항목 요약
- 보조 안내 문구
- 하단 2CTA

## 화면 구조

- 상단에는 `예약 확정` 타이틀이 있는 navigation 영역이 배치된다.
- 본문 중앙에는 완료 아이콘과 예약 요약 정보가 수직 정렬된다.
- 하단에는 예약 내역을 어디서 다시 확인할 수 있는지 보조 문구가 노출된다.
- 최하단에는 `닫기`, `보러가기` 2CTA가 배치된다.

## AI 참고 포인트

- 완료 화면은 정보량이 적고 정서적 확인이 핵심이므로, 중앙 정렬된 success confirmation 레이아웃으로 해석한다.
- CTA는 한 개가 아니라 동일 비중의 2버튼 구조다.
